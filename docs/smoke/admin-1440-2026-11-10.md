# 관리자 콘솔 1440px 스모크 — 2026-11-10

이슈 #60의 증거. 실제 Chrome(Playwright `channel: chrome`, headless)으로 1440×900 화면을 방문했다.

## 실행

```bash
docker compose up -d --wait
cd service-new && ./gradlew bootRun
# 다른 셸
cd service-new
npm install --no-save playwright
OUT_DIR=../docs/smoke/2026-11-10 node scripts/admin-smoke.mjs
```

- 로컬 DB는 V3에서 V4로 자동 마이그레이션됐고, 시드 관리자 계정은 `admin@lookation.local` / `lookation-admin1!`.
- 스모크 계정: `admin@lookation.local` (관리자 전용 로그인).
